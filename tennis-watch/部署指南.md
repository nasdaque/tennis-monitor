# 网球场空场监控 —— 从零开始部署指南

这套工具会每 15 分钟自动检查一次 Poplar Rec Ground 网球场的订场页面，一旦你想要的时间段出现空场（有价格显示），就会给你手机推送通知。全程免费，你的电脑不需要一直开机。

一共分 4 步：
1. 注册 GitHub 账号，建一个仓库，把文件传上去
2. 设置手机推送（ntfy）
3. 按你的需求修改配置文件
4. 打开定时任务，测试一下

---

## 第一步：注册 GitHub 并创建仓库

GitHub 是一个可以免费托管代码、并免费提供"定时自动运行"功能的平台，我们用它来代替你自己的电脑。

1. 打开 https://github.com/signup ，注册一个账号（需要邮箱）。
2. 登录后，右上角点击 **+** → **New repository**。
3. Repository name 随便填，比如 `tennis-watch`。
4. **Visibility 选 Public（公开）**——这一点很重要：公开仓库使用 GitHub Actions 定时任务是完全免费、不限次数的；如果选 Private，每月有免费额度限制，可能不够用。（仓库里不会有你的隐私信息，公开也没关系。）
5. 点击 **Create repository**。

### 把文件传上去

在新建好的空仓库页面，你会看到 "uploading an existing file" 的链接（或者点击 **Add file → Upload files**）。

把我给你的这些文件/文件夹，**保持原来的文件夹结构**上传上去：

```
tennis-watch/
├── monitor.py
├── config.json
├── requirements.txt
├── state.json
└── .github/
    └── workflows/
        └── check.yml
```

⚠️ 注意：`.github/workflows/check.yml` 这个路径的文件夹结构必须完全保留，不能把 `check.yml` 直接扔在最外层。如果网页上传界面不方便建文件夹，可以直接把整个 `.github` 文件夹拖进上传区域，GitHub 会自动保留目录结构。

上传完后点击 **Commit changes** 提交。

---

## 第二步：设置手机推送通知（ntfy）

ntfy 是一个免费、不需要注册账号的推送服务，原理是：你在手机订阅一个"频道名"，程序往这个频道发消息，你手机就收到通知。

1. 手机应用商店搜索并安装 **ntfy**（iOS 和 Android 都有）。
2. 打开 App，点击右下角 **+**，输入一个**只有你自己知道的、独一无二的频道名**，比如：
   `zhang-tennis-poplar-8823`（别人如果猜中这个名字，理论上能看到你收到的通知，所以尽量起得复杂一点，不要用简单的词）。
3. 点击订阅（Subscribe）。
4. 记住这个名字，下一步要填到配置文件里。

（如果你有 iPhone，也可以用 Bark App 代替，原理类似，只是本指南以 ntfy 为例。）

---

## 第三步：修改配置文件，填上你的需求

在你的 GitHub 仓库里，点击 `config.json` 文件，再点右上角铅笔图标（Edit），改成你自己的设置：

```json
{
  "base_url": "https://tennistowerhamlets.com/book/courts/poplar-rec-ground",
  "days_ahead": 7,
  "desired_times": ["18:00", "19:00", "20:00"],
  "weekdays": null,
  "ntfy_topic": "zhang-tennis-poplar-8823"
}
```

各项含义：

- `base_url`：场地页面地址，默认就是 Poplar Rec Ground。如果你想监控别的场地（比如 Victoria Park），把网址换成对应场地的即可，格式类似。
- `days_ahead`：往后检查几天，网站最多能提前 7 天订场，所以填 7 就够了。
- `desired_times`：你想要的开始时间，24 小时制，比如晚上 6-9 点想要任意一个空场，就填 `["18:00", "19:00", "20:00"]`。
- `weekdays`：如果只想在周末找场地，填 `[5, 6]`（0=周一 … 5=周六，6=周日）；不限制的话填 `null`。
- `ntfy_topic`：改成你在第二步里设置的频道名。

改完后点击 **Commit changes** 保存。

---

## 第四步：手动测试一次

1. 在仓库页面点击顶部的 **Actions** 标签。
2. 左边选择 "检查网球场空场"。
3. 右边会有 **Run workflow** 按钮，点击它，再点绿色的 **Run workflow** 确认。
4. 等 1-2 分钟，刷新页面，能看到一个正在运行/已完成的任务，点进去可以看到详细日志，确认有没有报错。
5. 如果配置的时间段刚好当前有空场，几分钟内你手机就会收到 ntfy 推送。

之后它会**每 15 分钟自动运行一次**，不需要你再做任何操作。

## 关于误判/没收到通知怎么办

这个网站的页面内容是用程序动态生成的，我在准备这套脚本时没法完全模拟出和你浏览器一模一样的加载效果，所以判断逻辑（"看到价格 = 有空场，看到 Full = 满场"）是基于网站公开说明写的，第一次实测时**有一定概率需要微调**。

如果测试后发现：
- Actions 日志里报错 → 把报错内容截图/复制发给我，我帮你看
- 明明有空场但没收到通知，或者收到了错误的通知 → 把当时那天的订场页面截图发给我，我帮你调整脚本里的判断逻辑

## 修改检查频率

如果 15 分钟对你来说太频繁或太稀疏，可以编辑 `.github/workflows/check.yml` 里的这一行：

```
- cron: '*/15 * * * *'
```

比如改成 `*/5 * * * *` 就是每 5 分钟一次（GitHub 对公开仓库的免费额度很宽松，但过于频繁意义也不大，订场页面本身更新也没那么快）。
